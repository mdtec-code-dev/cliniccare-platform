# 🚀 MVP Definition

Este documento define el **Minimum Viable Product (MVP)** de CLINICARE.

El MVP representa la **primera versión funcional**, no la versión final.

---

## 🎯 Objetivo del MVP

- Validar la arquitectura API-First
- Permitir trabajo paralelo frontend/backend
- Cubrir flujos clínicos básicos
- Implementar seguridad mínima viable

---

## ✅ Funcionalidades incluidas

### 🔐 Autenticación

- Login con JWT
- Refresh token
- Roles básicos

---

### 👤 Gestión de pacientes

- Crear paciente
- Editar paciente
- Listar pacientes
- Ver detalle

---

### 📅 Turnos médicos

- Crear turno
- Listar turnos
- Cambiar estado
- Validar solapamientos

---

### 🧾 Historia clínica (básica)

- Crear registro médico
- Asociar a paciente
- Ver historial

---

## ❌ Fuera del MVP

Estas funcionalidades **NO forman parte del MVP**:

- Facturación
- Reportes
- Auditoría avanzada
- Notificaciones
- Integraciones externas

---

## 📌 Regla del MVP

> **Si no aporta a validar la arquitectura o el flujo, no entra al MVP.**
