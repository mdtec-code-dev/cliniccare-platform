# 👥 Team Rules

Este documento define las **reglas de trabajo del equipo CLINICARE**.

El objetivo es:

- mantener orden
- evitar fricción
- fomentar aprendizaje
- simular trabajo profesional

---

## 🤝 Principios del equipo

- Respeto técnico
- Comunicación clara
- Calidad sobre velocidad
- Aprender del error
- Decisiones justificadas

---

## 🔐 Reglas de código

- No se pushea directo a `main` ni `develop`
- Todo cambio va por PR
- Un PR = una responsabilidad
- Código legible > código complejo

---

## 🧠 Responsabilidades

### Tech Lead

- Arquitectura
- Reglas técnicas
- Revisión de PRs
- Decisiones finales

### Backend Devs

- Lógica de negocio
- Seguridad
- Endpoints
- Tests

### Frontend Devs

- UX
- Integración API
- Manejo de estados
- Validaciones visuales

---

## 🧪 Testing

- Todo feature debe probarse manualmente
- Bugs se reportan como issues
- No se mergea código roto

---

## 🗣️ Comunicación

- Dudas técnicas → issue o PR
- Decisiones grandes → documentadas
- Feedback siempre constructivo

---

## 📌 Regla final

> **Este proyecto es un entorno de aprendizaje serio, no un experimento sin reglas.**
