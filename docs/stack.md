# 🧱 Technology Stack

Este documento describe el **stack tecnológico oficial** del proyecto CLINICARE.

Las tecnologías fueron elegidas por **criterio técnico**, no por tendencia.

---

## 🧠 Backend

- Python 3.12
- Django
- Django REST Framework
- PostgreSQL
- Celery
- Redis
- JWT (Access + Refresh)
- OpenAPI / Swagger

---

## 🎨 Frontend

- Next.js
- TypeScript
- Tailwind CSS
- Fetch / Axios
- App Router
- Middleware de autenticación

---

## 🐳 Infraestructura

- Docker
- Docker Compose
- Variables de entorno
- Logs estructurados

---

## 🧪 Testing

### Backend

- Tests unitarios
- Tests de servicios
- Tests de permisos

### Frontend

- Validación de flujos
- Estados (loading / error)

---

## 📌 Principio del stack

> **Elegimos tecnologías que el equipo domina y que permiten aprender arquitectura real.**
